World In A Cell is a VR educational game developed by USC World Building Media Lab to help students understand complex cell biology concepts.

As the VR UX Designer, I led the VR interaction flow and user interface design, and organized more than 30 usability tests and scenario tests.

Project outcomes:

- Improved user immersion and learning efficiency;
- Used usability testing to solve operation and comprehension pain points;
- Collaborated with biological scientists to develop a VR learning tool for classroom teaching;
- The project was introduced into USC biology courses in the Fall 2023 semester.
